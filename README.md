# About

Helix Codex is a project I'm building to learn more about robotics, software engineering, and interactive user interfaces.

The idea is simple.

Instead of presenting robotics as static documentation, I wanted to build an interface that feels like a real control system. The project combines interactive dashboards, simulated telemetry, modular educational content, and modern web technologies into one experience.

This isn't a finished product.

It's a project that grows every time I learn something new.



# Current Features

* Responsive interface
* Cyber-inspired design system
* Interactive module pages
* Robotics dashboard
* Telemetry visualization
* Teleoperation controls

# Goals

The long-term goal of Helix Codex is to become an interactive platform that helps students understand robotics, programming, and biomedical engineering through practical visual experiences instead of static lessons.
