Helix Codex



## Day 1

Started collecting references and exploring different ideas.

## Day 2

Started building the first layout.

Experimented with different UI directions before choosing a darker interface.



## Day 3

Built the first version of the landing page.

Created reusable components instead of writing everything inside one file.

Learned more about component structure and project organization.



## Day 4

Started working on the design system.

Created reusable colors and spacing variables.

Moved repeated styles into shared files.



## Day 5

Integrated Spline into the project.

Spent a long time experimenting with different scenes and camera positions.

Learned how to combine interactive 3D content with React components.



## Day 6

Started building the modules section.

Focused on making the interface easy to navigate.

Reorganized several components after noticing duplicated code.



## Day 7

Built the dashboard layout.

Added telemetry cards and system information.

The values are currently simulated but the structure is ready for future backend integration.


## Day 8

Created the teleoperation interface.

Added switches, buttons, and placeholder controls for future robot communication.

Prepared the UI so it can later connect to a real backend.



## Day 9

Improved responsiveness.

Fixed layout issues on smaller screens.

Reduced repeated CSS by creating reusable utility classes.



## Day 10

Prepared the project for deployment.

Optimized the build.

Fixed import errors.

Verified that the application runs correctly on Vercel.



## What Went Wrong

I spent too much time trying to make everything perfect before publishing anything.

Because of that, I wasn't making regular commits and I wasn't documenting my progress.

Reading the Hack Club Shipping Guide made me realize how important consistent progress is.

That lesson changed the way I work.



## What I Learned

* Build first.
* Improve later.
* Commit often.
* Keep the project organized.
* Document the journey.
* Don't wait for perfection.
